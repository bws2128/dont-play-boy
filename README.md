# Don't Play Boy — website

One page, no build step: `index.html` plus two images in `images/`.

## Edit it
- **Tagline / About / wording:** open `index.html`, find the text, change it, save.
- **Headshot:** replace `images/headshot.jpg` (same filename).
- **Lion logo (the reveal):** replace `images/lion.png` (white art, transparent background).
- **Listen links:** in `index.html`, the three button `href="#"` become your
  Spotify / Apple Podcasts / YouTube URLs.

## Publish a change
From this folder:

    git add -A
    git commit -m "Update site"
    git push

GitHub Pages redeploys automatically in about a minute.

Live at https://bws2128.github.io/dont-play-boy/
